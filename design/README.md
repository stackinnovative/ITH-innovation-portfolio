# Design files

Approved design for the ITH Innovation site, exported from the design canvas.

| File | What it is | Size |
|---|---|---|
| Main.dc.html | Home page, desktop | 1440 wide |
| Projects.dc.html | Projects page, desktop | 1440 wide |
| Mobile.dc.html | Home page, phone | 390 wide |

These files are a **spec, not code to reuse**. They use a design-tool runtime (`support.js`, `<x-dc>`, `<sc-for>`, `{{holes}}`) that won't run on its own. Read the inline styles for exact sizes and colors. Read the `<script>` block at the bottom for list data (it matches `content/site.ts`).
